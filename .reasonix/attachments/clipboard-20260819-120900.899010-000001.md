# 二、产品定位

这是一个面向成年人的长期个人健康档案 App。

核心目标：

帮助用户长期记录：

- 医院检查
- 体检
- 检验报告
- 健康指标
- 疾病史
- 用药记录
- 日常健康数据

未来会通过 OCR 和 AI 将医院报告结构化，但当前版本不要开发这些功能。

当前阶段只开发：

“可点击、可浏览、视觉完整的 MVP UI 原型”。
