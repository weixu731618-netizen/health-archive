# 四、百度 OCR

使用：

通用文字识别（高精度含位置版）

通过官方 REST API 调用。

流程：

API Key + Secret Key
→ 获取 access_token
→ 调用 OCR 接口

access_token 应在后端缓存，不要每张图片都重新申请。

---

# 五、FastAPI 接口

实现：

POST /api/report/ocr

multipart/form-data

字段：

file

只接受：

- image/jpeg
- image/png

返回统一 JSON：

{
  "success": true,
  "wordsCount": 32,
  "words": [
    {
      "text": "尿酸",
      "left": 100,
      "top": 200,
      "width": 80,
      "height": 30
    }
  ]
}

如果百度原始返回字段不同，可以在后端做统一转换。

---

# 六、错误处理

必须处理：

- API Key 无效
- Secret Key 无效
- access_token 获取失败
- OCR 服务调用失败
- 图片格式错误
- 图片过大
- 网络超时
- 百度返回空结果

禁止直接把百度完整错误堆栈暴露给 Flutter 用户。
